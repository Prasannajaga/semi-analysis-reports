1. Performance & Latency Details

Output TPS (generated tokens/sec, higher is better) vs TTFT latency (p95 ms, lower is better).

Provider Output TPS RPS TTFT Mean TTFT p95 ITL p95 E2E p95
Formulas:
  • • Output TPS = Total Generated Completion Tokens ÷ Workload Duration (s)
  • • Request Throughput (RPS) = Total Completed Requests ÷ Workload Duration (s)
  • • TTFT = Timestamp of First Stream Token − Timestamp of Request Dispatch
  • • ITL = (E2E Latency − TTFT) ÷ (Total Generated Tokens − 1)
  • • E2E Latency = Timestamp of Final Response Token − Timestamp of Request Dispatch

2. Cost Economics Details

Measured workload spend and effective cost normalized per 1,000 successful requests.

Provider Workload Cost $ / 1k Attempts $ / 1k Successful Prompt ($/1M) Completion ($/1M) Input Tokens Output Tokens
Formulas:
  • • Workload Spend ($) = (Uncached Tokens × Input Rate + Cached Tokens × Cached Rate + Output Tokens × Output Rate) ÷ 1,000,000
  • • Cost / 1k Successful = (Total Workload Spend ÷ Successful Requests) × 1,000
  • • Cost / 1k Attempts = (Total Workload Spend ÷ Total Requests) × 1,000
  • • Cost / Request = Total Workload Spend ÷ Total Requests

4. Cache Hit Rate & Prefix Caching Details

Prompt cache hit ratio (%, higher is better) and discounted cached token pricing economics.

Provider Cache Hit Rate Cached Tokens Total Input Tokens Standard Rate ($/1M) Cached Rate ($/1M) Cache Savings
Formulas:
  • • Cache Hit Rate (%) = (Cached Prompt Tokens ÷ Total Input Tokens) × 100
  • • Cache Savings ($) = (Cached Tokens × [Standard Input Rate − Cached Input Rate]) ÷ 1,000,000
  • • Uncached Tokens = Total Input Tokens − Cached Prompt Tokens
